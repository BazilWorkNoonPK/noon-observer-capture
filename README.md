# Noon Qalam - Observer capture pages

Static pages that run in a second Chrome tab on a classroom machine. No data, no key, no name lives here.
Source and history: the private noon-qalam repository, pilot/observer/capture/.

- / : the capture page (capture@0.1.0): records the classroom USB mic on the campus timetable and uploads to Noon's endpoint.
- p0/ : the P0 microphone test page (nothing is uploaded by it).
